# Concept Directions

Use these as the default option families when proposing 3–4 SVG hero concepts.

## 1) Minimal Terminal Hero
Best for CLI tools, developer utilities, scripts, and agent shells.

**Look**
- dark background
- prompt line
- compact status chips
- subtle terminal frame

**Strength**
- instantly readable
- low clutter
- feels technical and credible

**Risk**
- can feel generic if not anchored to repo-specific terms

## 2) Architecture Diagram Hero
Best for AI systems, frameworks, orchestration tools, backend platforms.

**Look**
- central node
- connected modules
- thin lines
- restrained labels

**Strength**
- communicates system structure quickly
- works well for modular projects

**Risk**
- can become busy if too many nodes are added

## 3) Editorial Title Card
Best for polished libraries, design repos, docs-heavy projects, and clean brands.

**Look**
- oversized title
- short subtitle
- lots of whitespace
- one or two accent glyphs or shapes

**Strength**
- premium and minimal
- easy to read in README thumbnails

**Risk**
- may under-explain highly technical repos

## 4) Geometric Signal Card
Best for experimental tools, creative programming projects, or repos with a distinctive identity.

**Look**
- grids, rings, bars, or layered panels
- abstract but structured
- short labels only

**Strength**
- visually memorable
- can look original without becoming noisy

**Risk**
- must be carefully constrained or it becomes decorative noise
